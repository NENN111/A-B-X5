# Notebooks

Jupyter Notebook используются только для исследования, объяснения и визуализации. Переиспользуемая логика ETL, статистики, построения признаков и моделирования находится в `src/`.

`01_data_overview.ipynb` исследует данные, `02_ab_analysis.ipynb` визуализирует A/B-результат, `03_experiment_validation.ipynb` показывает SRM, A/A, bootstrap и сегментные эффекты, а `05_uplift_modeling.ipynb` — Qini, AUUC, децильные таблицы и распределение predicted uplift. Notebook не содержат заранее рассчитанных или искусственных результатов.

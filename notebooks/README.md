# Notebooks

Jupyter Notebook используются только для исследования, объяснения и визуализации. Переиспользуемая логика ETL, статистики, построения признаков и моделирования находится в `src/`.

`01_data_overview.ipynb` вызывает модули Stage 2. `02_ab_analysis.ipynb` визуализирует результат A/B engine Stage 4. `03_experiment_validation.ipynb` показывает SRM, A/A, bootstrap и сегментные эффекты Stage 5. Notebook не содержат заранее рассчитанных или искусственных результатов; остальные будут добавляться вместе с соответствующими этапами.

# Notebooks

Jupyter Notebook используются только для исследования, объяснения и визуализации. Переиспользуемая логика ETL, статистики, построения признаков и моделирования должна находиться в `src/`.

Планируемая последовательность: обзор данных, A/B-анализ, валидация эксперимента, построение признаков, uplift-моделирование и бизнес-анализ. Каждый notebook будет вызывать протестированные модули, а не реализовывать отдельную версию pipeline.

# Notebooks

Jupyter Notebook используются только для исследования, объяснения и визуализации. Переиспользуемая логика ETL, статистики, построения признаков и моделирования находится в `src/`.

`01_data_overview.ipynb` исследует данные, `02_ab_analysis.ipynb` визуализирует A/B-результат, `03_experiment_validation.ipynb` показывает SRM, A/A, bootstrap и сегментные эффекты, `05_uplift_modeling.ipynb` — Qini, AUUC и predicted uplift, а `06_business_analysis.ipynb` — сценарную экономику и чувствительность к порогу. Notebook не содержат заранее рассчитанных или искусственных результатов.

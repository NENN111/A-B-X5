# Notebooks

Jupyter Notebook используются только для исследования, объяснения и визуализации. Переиспользуемая логика ETL, статистики, построения признаков и моделирования находится в `src/`.

`01_data_overview.ipynb` подготовлен на Stage 2 и вызывает модули загрузки, профилирования и очистки. Он не содержит заранее рассчитанных или искусственных результатов. Остальные notebooks будут добавляться вместе с соответствующими этапами проекта.

# Тесты

Unit-тесты добавляются вместе с аналитическими модулями. На Stages 2–3 покрыты обнаружение исходных файлов, настройки путей, профили качества, очистка, аудит Parquet, schema mapping, temporal leakage guard, RFM и клиентская витрина.

Запуск:

```bash
pytest
```

На следующих этапах будут добавлены эталонные статистические примеры, граничные случаи, воспроизводимость и инварианты uplift-метрик.

# Тесты

Unit-тесты добавляются вместе с аналитическими модулями. На Stage 2 покрыты обнаружение исходных файлов, настройки путей, профили качества, безопасная очистка и аудит Parquet-выгрузки.

Запуск:

```bash
pytest
```

На следующих этапах будут добавлены эталонные статистические примеры, граничные случаи, воспроизводимость и инварианты uplift-метрик.

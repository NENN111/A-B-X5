# Тесты

Unit-тесты добавляются вместе с аналитическими модулями. На Stages 2–4 покрыты data layer, schema mapping, temporal leakage guard, RFM, клиентская витрина, метрики A/B-теста, доверительные интервалы, power analysis и Parquet-интеграция. Статистические формулы сверяются с `statsmodels`, а также проверяются через ручные примеры и математические инварианты.

Запуск:

```bash
pytest
```

На следующих этапах будут добавлены эталонные статистические примеры, граничные случаи, воспроизводимость и инварианты uplift-метрик.
